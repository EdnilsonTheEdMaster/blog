# Meu Blog Pessoal

Projeto simples de blog feito com HTML, CSS e JavaScript. Nele, você pode criar
publicações com texto e imagem (por endereço ou escolhida no dispositivo) e
adicionar comentários.

## Como abrir

Abra o arquivo `index.html` em um navegador. Não é necessário instalar nada.

## Como usar

1. Preencha o título e o texto da publicação.
2. Se quiser exibir uma imagem, informe um endereço começando com `https://` ou
   `http://`, ou selecione um arquivo de imagem de até 2 MB do dispositivo.
   Escolha apenas uma dessas opções por publicação.
3. Clique em **Publicar**.
4. Escreva um comentário no formulário abaixo de uma publicação e clique em
   **Comentar**.

As publicações, imagens e comentários ficam salvos no armazenamento local do
navegador (`localStorage`). Por isso, eles só aparecem no navegador e dispositivo
em que foram criados. Este projeto não tem servidor nem compartilha dados com
outros visitantes.
